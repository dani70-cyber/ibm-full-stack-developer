# IBM Full Stack Software Developer: Learning Journey

My learning reference for the IBM Full Stack Software Developer course (audited, no certificate): notes, labs, exercises and projects, organised course by course.

## Why this repo

I have 2-3 months of internship experience in web development, mainly backend, where I focused on improving application security using AI together with my own knowledge. I am taking this course to:

- Refresh my core concepts and build a stronger grip on web development
- Learn to build more scalable and feasible web apps with better security
- Get more hands-on coding experience and sharpen my problem-solving
- Strengthen system design fundamentals for interview prep and future projects

## Note on certification

I am committing from a friend's group GitHub account, so a certificate cannot be issued in my name. This repo is my proof of work: every lab, note and exercise from the course lives here.
